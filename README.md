# Подборка вин — ДЗ 3

Приложение использует логистическую регрессию для отбора вин с оценкой не ниже 7.
Весь пайплайн (StandardScaler + LogisticRegression) обучен в ноутбуке.
Порог выбран по максимуму F1 на валидационной части тренировочной выборки.
При запуске приложения обучение не выполняется.

## Запуск

Проверяется на Python 3.12.3. Откройте терминал в папке `wine_app`:

```bash
python -m venv .venv
```

Активация в Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

На Linux/macOS: `source .venv/bin/activate`.

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Откройте локальный адрес, который напечатает Streamlit (обычно http://localhost:8501).
Можно запускать и из другой папки, указав полный путь к app.py: файлы модели читаются относительно самого скрипта.

## Что находится во вкладках

- «Одно вино»: 11 числовых признаков и переключатель цвета, вероятность и решение.
- «Модельные метрики»: матрица ошибок, precision, recall, F1, ROC и PR с текущей точкой.
- «Загрузить CSV»: пример входного файла, пакетный прогноз и скачивание результата. Пропущенные столбцы, пустые данные, нечисловые значения и пропуски выводятся как понятная ошибка.
- «Что выучила модель»: коэффициенты при стандартизованных признаках и их краткая интерпретация.

Общий порог находится слева. Значение по умолчанию читается из config.json.
Тестовая вкладка нужна для демонстрации, а не для подбора порога по тесту.

## Данные и файлы

- model.joblib — обученный пайплайн sklearn.
- config.json — выбранный на валидации порог.
- test.csv — отложенные данные с target.
- requirements.txt — версии используемых библиотек.
