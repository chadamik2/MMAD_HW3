# Подборка вин — ДЗ 3

Приложение использует логистическую регрессию для отбора вин с оценкой не ниже 7.
Весь пайплайн (StandardScaler + LogisticRegression) обучен в ноутбуке.
Порог выбран по максимуму F1 на валидационной части тренировочной выборки.
При запуске приложения обучение не выполняется.

## Запуск

Проверяется на Python 3.12.3. Откройте терминал в папке `wine_app`:

```bash
python -m venv .venv
```

Активация в Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

На Linux/macOS: `source .venv/bin/activate`.

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Откройте локальный адрес, который напечатает Streamlit (обычно http://localhost:8501).
Можно запускать и из другой папки, указав полный путь к app.py: файлы модели читаются относительно самого скрипта.

## Что находится во вкладках

- «Одно вино»: 11 числовых признаков и переключатель цвета, вероятность и решение.
- «Модельные метрики»: матрица ошибок, precision, recall, F1, ROC и PR с текущей точкой.
- «Загрузить CSV»: пример входного файла, пакетный прогноз и скачивание результата. Пропущенные столбцы, пустые данные, нечисловые значения и пропуски выводятся как понятная ошибка.
- «Что выучила модель»: коэффициенты при стандартизованных признаках и их краткая интерпретация.

Общий порог находится слева. Значение по умолчанию читается из config.json.
Тестовая вкладка нужна для демонстрации, а не для подбора порога по тесту.

## Зачем кэширование

`st.cache_resource` хранит один объект модели на сервере. Модель не копируется и не загружается с диска при каждом изменении ползунка.
`st.cache_data` предназначен для результатов вычислений и таблиц: Streamlit сериализует результат и выдаёт его копию.
Так кэшируются тестовая таблица и вероятности на ней. Аргумент `_model` не хешируется.
При смене порога меняются только метки и пороговые метрики; тестовый predict_proba повторно не вызывается.
Без декоратора joblib.load заново читал бы модель при каждом перезапуске скрипта.
Если заменить файл модели во время работы сервера, нужно очистить кэш или перезапустить приложение.

## Публикация в Streamlit Community Cloud

Публичный деплой пока не выполнен: нужен доступ к GitHub и Streamlit владельца.

1. Добавить всю папку wine_app в GitHub-репозиторий, включая model.joblib, config.json и test.csv.
2. Войти в Streamlit Community Cloud и выбрать Create app.
3. Указать репозиторий, ветку и путь `wine_app/app.py` (или `app.py`, если содержимое папки лежит в корне).
4. В расширенных настройках выбрать Python 3.12 и нажать Deploy.
5. После успешного запуска добавить публичную ссылку в последнюю ячейку ноутбука.

Официальная инструкция: https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app
